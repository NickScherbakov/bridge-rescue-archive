## 🎯 How to Get on the Leaderboard

1. **Make a contribution** - Code, docs, research, design, or community
2. **Submit a PR** - Your contribution gets reviewed
3. **Get merged** - PR is approved and merged
4. **Earn points** - Points automatically added
5. **Claim badges** - Badges awarded based on achievements

## 🔄 Updating the Leaderboard

The leaderboard is updated automatically via GitHub Actions when:
- PRs are merged
- Missions are completed
- Badges are awarded

### Manual Update

Maintainers can manually update using:

```bash
# Add contribution
python leaderboard/ranking-system.py add \
  --username johndoe \
  --points 25 \
  --category code

# Complete mission
python leaderboard/ranking-system.py mission \
  --username johndoe \
  --mission mission-4-chrome-extension \
  --points 60

# Export leaderboard
python leaderboard/ranking-system.py export
```
